    Methodology

    Built with Equilibrium, a macOS GTO poker lab with a Rust DCFR solver.

    Reproduce it

    make bench-cli
export OPENROUTER_API_KEY=sk-or-...
eqbench bench generate --decisions 200 --seed 2026
eqbench bench baselines --suite <id>
eqbench bench run --suite <id> --models typesafe/jev-1.13,liquid/d1,…
eqbench bench export          # → web/data/results.json
